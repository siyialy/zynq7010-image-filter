# 人工标注集入口

日期：2026-10-25。现已建立离线标注工具，入口为根目录 `打开病斑标注工具.cmd`。

详见 [标注工具使用说明](../annotation_tool/使用说明.md)。

24 张程序输入 RGB 图片已原样导出，65 个 PL 候选标记为待确认；初始状态没有任何人工真值，也没有任何图片自动通过审核。

流程：逐张确认/排除候选 → 手动补画漏检 → 修正完整病斑边界 → 标记整张审核完成 → 导出 JSON → 拖到 `评估病斑标注.cmd` → 查看逐图漏检/误框报告。

只有人工确认类别为病斑的框作为真值。背景 / 非病斑不会被当作评估忽略区；不确定区域单独报告。源图候选框和带边距的 HDMI 框投影分别评估。

这些图片仍为开发集。标注文件不是训练后的模型，不会自动改变 PL 检测；应先用真值定位错误来源，再离线验证算法改动并进行 RTL/上板核对。
