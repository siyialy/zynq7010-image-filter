# 板卡识别报告（根据你发的实物照片）

## 结论

**正点原子 启明星 ZYNQ 开发板 7010 版（V2）**，核心板型号丝印 `CF7010B/7020B`，主芯片 `XC7Z010-1CLG400C`。
板上白色标签写着「正点原子 ZYNQ 7010版」，右侧丝印「正点原子启明星」，和你老师给的资料页完全对应。

## 从照片上确认到的接口（逐个核对过丝印）

| 位置 | 丝印 | 说明 | 对我们的项目 |
|---|---|---|---|
| 右侧 | **HDMI OUT** | 标准 HDMI 母座，**只有输出，没有输入** | ✅ 视频输出走这里，接显示器 |
| 下方偏左 | **OLED/CAMERA** | 2×9 排针，丝印信号：`GND SCL SDA D0 D2 D4 D6 PCLK PWDN …` | ✅ 摄像头（OV5640 DVP 8bit + I2C）接这里；OLED 也用这组的 SCL/SDA，两者共用 |
| 右侧 | **JTAG** | 2×7 = 14 脚标准 Xilinx JTAG 排针 | ⚠️ **需要外接下载器**，板子没有板载 USB-JTAG |
| 左侧 | **USB UART** | Micro-USB + `CH340C`，丝印有 `PS_TX` / `PL_TX` | ✅ 串口打印走这里（先确认跳线选的是 PS_TX） |
| 左上 | **USB HOST** | USB-A 母座 | 暂不用 |
| 左侧 | USB SLAVE ×2 | Micro-USB，PS 端 USB OTG | 暂不用 |
| 左上 | **TF CARD** | Micro SD 卡槽 | 后面做 SD 卡启动时用 |
| 上方 | **GE_PS** | 千兆网口（PS 端） | 可选：上位机通信 |
| 中下 | **BOOT CFG** 拨码 | 表：`JTAG=ON/ON`、`NAND=OFF/ON`、`QSPI=ON/OFF`、`SD=OFF/OFF` | ✅ 用 JTAG 下载时，两个开关都拨到 **ON** |
| 中下 | **PL KEY0 / PL KEY1**、**PS KEY0 / PS KEY1**、`RESET` | 2 个 PL 按键、2 个 PS 按键、复位键 | 后面做模式切换用 PL KEY |
| 中下 | **PL LED0 / PL LED1**、**PS LED0 / PS LED1** | 2 个 PL 灯、2 个 PS 灯 | ✅ 第一个上板实验就点 PL LED0 |
| 核心板旁 | `POR`、`PS_RST`、`RECONFIG` | 上电复位、PS 复位、重配置排针 | 别乱动 |
| 左下 / 左侧 | `7020 DMLY`、`A`、`B` 长排针 | PL 扩展 IO 排针（标注了 V8/U7/U8… 等引脚名） | 备扩展 |
| 右下 | `ATK MODULE` | 正点原子模块接口 | 暂不用 |

> **重要提醒**：左下角那排长排针丝印写着 `7020 DMLY`（7020 only），这是给 7020 版本的额外 IO。你这块是 7010，这排不一定全通，**不要随便往上面接东西**。

## 三个关键结果

### 1. 没有 LCD，也不需要 LCD

你说"没有 LCD 显示屏"是对的——这块板**本来就没有 LCD 接口**（长排针是裸 PL IO，不是 LCD 座）。
显示只能走 **HDMI OUT → 显示器**。所以你需要：**一根 HDMI 线 + 一台带 HDMI 输入的显示器/电视**。这个必须有，否则后面看不到任何图像。

### 2. 没有 HDMI 输入 → 视频源只能用摄像头

所以项目链路确定为：

```
OV5640 摄像头 → （DVP 并口）→ PL 采集 → PL 3×3 滤波加速 → HDMI OUT → 显示器
                                    ↑
                             PS(ARM) 通过 AXI 配置参数
```

这对我们反而更有利：摄像头是"真实实时视频源"，比 HDMI 环出更能体现"实时"，评委也更认。

### 3. 板子没有板载下载器，必须有一个外接 JTAG 下载器

这是**最容易忽略、但没它什么都干不了**的东西。板上只有 2×7 的 JTAG 排针，需要一根下载器插上去。

可选（任选其一，几十到一百多元）：
- 正点原子 `ATK-XDS100` / `ATK-XDS200`（配套，最省心）
- 国产兼容 `Xilinx Platform Cable USB II`（淘宝常见，二三十元）
- Digilent `JTAG-HS2` / `JTAG-HS3`（原厂，贵但稳）

买/借的时候注意：**要"Xilinx 兼容"的，不是 Altera 的 USB Blaster**。排线要有 14 脚的（2×7, 2.0mm 间距）那一端。

## 还需要你确认的东西（会影响下一步能不能开工）

| 需要 | 用途 | 没有怎么办 |

## 待确认的技术细节（等原理图）

| 问题 | 为什么重要 |
|---|---|
| HDMI 输出是 PL 直接驱动 TMDS，还是经 TFP410 / ADV7511 之类的发送芯片？ | 决定我们要不要写 TMDS 编码器、要不要配 I2C。看原理图和 HDMI 例程就知道 |
| PL 端晶振频率 | 时序约束和分频参数要用 |
| 摄像头排针完整定义（D1/D3/D5/D7、VSYNC、HSYNC、RST 在第几脚） | 写采集模块的引脚约束 |
| DDR3 型号 | PS 端 DDR 配置，配错会启动失败 |

这四个问题，**资料一到就全解决**。所以下一步唯一任务是：下载资料（见 [03_board_materials.md](03_board_materials.md)）。
