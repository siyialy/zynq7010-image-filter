# 上板操作卡（第一次通电，按顺序做）

> 目标：从"冷板子"到"显示器出彩条 + 按 KEY1 看到你的照片"。
> 每一步都有**成功标志**，卡住了就停下看"故障表"，别往下跳。

---

## 准备清单

| 东西 | 数量 | 说明 |
|---|---|---|
| 启明星 ZYNQ-7010 板子 | 1 | |
| 12V/1A 电源适配器（5.5×2.1，中心正极） | 1 | 插头规格要对 |
| PTD04 下载器 + 14 脚排线 | 1 | |
| Micro-USB 线 | 1~2 | 下载器一根；串口调试再一根 |
| HDMI 线 | 1 | |
| 带 HDMI 输入的显示器/电视 | 1 | |

---

## 第 1 步：断电状态接线（⚠️ 一定要断电）

1. 板子**不接电源**
2. **BOOT CFG 两个拨码都拨到 ON**（表上 `JTAG = ON/ON`）
3. 14 脚排线一头插 **PTD04 下载器**，另一头插板子 **JTAG** 座
   - 排线有防呆缺口，插不进就是方向反了，**别硬怼**
4. HDMI 线插板子 **HDMI OUT**
5. 下载器 USB 插电脑（优先主板后置口）

> ❌ 别把任何东西插到左下角标 `7020 DMLY` 的那排针上（7010 不保证通）

---

## 第 2 步：上电

接上 12V 电源。

**成功标志**：
- 板上 **`PWR` 灯亮**
- 电脑"设备管理器"里出现新设备（可能带黄色感叹号，正常，下一步装驱动）

**如果 PWR 灯不亮**：拔掉立刻检查电源极性/电压，别反复试。

---

## 第 3 步：装 USB 驱动（只需一次）

1. 右键开始菜单 → **「Windows PowerShell (管理员)」** 或「终端(管理员)」
2. 粘贴运行：

```
D:\XILINX\Vivado\2018.3\data\xicom\cable_drivers\nt64\install_drivers_wrapper.bat
```

3. 一路"下一步/安装"
4. 装完**拔插一次下载器**

---

## 第 4 步：让 Vivado 认出芯片（不建工程）

1. 打开 **Vivado 2018.3**
2. 左边 `Flow Navigator` 最下面 → 点 **`Open Hardware Manager`**
3. 上方点 **`Open target`** → **`Auto Connect`**
4. 等几秒

**成功标志**：Hardware 窗口出现这棵树

```
localhost (127.0.0.1)
└── xilinx_tcf/Digilent/xxxxx
    └── xc7z010_1        ← 看到它就算成功
```

**这是关键里程碑**：说明下载器、驱动、排线、供电、JTAG 焊点全部正常。

---

## 第 5 步：烧点灯程序（验证基础通路）

右键 `xc7z010_1` → **`Program Device`** → Bitstream file 填：

```
D:\fpga_build\bits\board_top_led.bit
```

> ⚠️ **必须用纯英文路径**。Vivado 的 Program Device 对话框不支持中文路径，
> 填 `D:\FPGA比赛\...` 会把"比赛"两个字吃掉，变成 `D:/FPGA/board/...` 然后报
> `The file ... does not exist`。所以 bit 文件统一放在 `D:\fpga_build\bits\`。

点 **`Program`**，等 3~5 秒。

**成功标志**（四个都要有）：

| 现象 | 说明什么 |
|---|---|
| LED0 以 1Hz 均匀闪烁 | ✅ 时钟通了 |
| 按住 **KEY1**，LED0 闪得明显变快 | ✅ 按键输入通了 |
| 每按一次 **KEY0**，LED1 翻转一次；松手不连跳 | ✅ 消抖正确 |
| 按 **RESET**，两灯回到初始状态 | ✅ 复位正常 |

---

## 第 6 步：烧 HDMI 图像程序（看画面）

同样操作，这次填：

```
D:\fpga_build\bits\hdmi_top.bit
```

**成功标志**：显示器在 2~3 秒内出图像。

| 操作 | 期望画面 |
|---|---|
| 上电/Program 后 | **8 条竖彩条**：白、黄、青、绿、品红、红、蓝、黑 |
| 按 **KEY0** 一次 | 灰度彩条（颜色变灰） |
| 再按 | 均值模糊（边缘变软） |
| 再按 | 高斯模糊（更自然的糊） |
| 再按 | **Sobel 边缘：全黑背景 + 7 条竖亮线**（位置在彩条交界处） |
| 按 **KEY1** | **切换到你的照片**（320×240 放大 3 倍居中，左右黑边） |
| 再按 KEY0 | 看你的照片被灰度/模糊/边缘处理 |

**看到"照片变 Sobel 轮廓"这个画面，就说明整个硬件加速系统跑起来了。**

---

## 第 7 步：记录（报告要用）

每成功一步，用手机拍一张：
1. Hardware Manager 里扫到 `xc7z010_1` 的截图
2. 板子亮灯的照片
3. 显示器出彩条的照片
4. 显示器出 Sobel 7 条线的照片
5. 显示器出照片 + 照片 Sobel 的照片

存到 `D:\FPGA比赛\report\photos\`，文件名写清楚（比如 `01_jtag_scan.png`、`04_sobel_colorbar.jpg`）。

## 故障表

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| PWR 灯不亮 | 电源极性/电压不对 | 立刻断电检查，别硬试 |
| 设备管理器无新设备 | USB 线是充电线 / 口没供电 | 换线、换后置 USB 口 |
| 设备管理器黄色感叹号 | 驱动没装 | 重跑第 3 步；或用设备管理器手动指向 `nt64` 目录 |
| `Auto Connect` 报 no cable found | 驱动不匹配 | 设备管理器看设备名，对应装 Xilinx / Digilent 驱动 |
| 扫到 cable 但没有芯片 | 排线方向反 / 板子没上电 / 拨码不是 JTAG | 逐项检查这三条 |
| 点灯正常，但 HDMI 无信号 | 显示器不接受 720p60 / HDMI 线 | 换显示器或电视试；确认线插的是 HDMI OUT |
| HDMI 全黑但有信号 | 复位键卡住 / MMCM 没锁 | 检查 RESET 键、`clk_locked`（板上无指示时只能靠换 bit 排除） |
| 花屏/雪花 | TMDS 差分对 P/N 接反 | 核对 J20/H20、K19/J19、G19/G20、J18/H18 |
| 偏色 | RGB 通道顺序 | `video_din[23:16]=R`、`[15:8]=G`、`[7:0]=B` |
| 能显示但轻微闪 | 帧率 60.6Hz（75MHz/1650/750） | 正常，多数显示器能接受 |
