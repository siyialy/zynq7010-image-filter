# v1.7：灰褐色病斑漏检与框覆盖

## 原因与修改

15、19的主要病斑在叶片掩膜内，具有足够局部对比度，但饱和棕色/严格绿色包围规则拒绝了偏灰褐、带黄化周边的候选。例如15候选源坐标(98,145)-(112,157)，122像素；19候选(106,160)-(112,168)，45像素，平均局部对比53。两者颜色饱和不足，周边严格绿色比例也不足。

增加灰褐色局部分支：候选面积至少20、四侧有组织支持、四侧组织比例总和至少290%、严格绿色比例总和至少60%、平均局部对比至少18。沿用叶片范围、形态学、形状、背景过滤；不按样本编号判定，不使用数据集标签触发检测。

对通过检查的核心，在满足叶片掩膜、局部对比、弱色度条件的相邻像素中最多扩展3步，以覆盖褪色边缘。扩展不能在其他位置产生新候选。area与置信度继续记录已验证核心的像素数/对比总和，框可包括扩展边缘及显示余量。

直接扩大候选颜色范围、在检查前扩展候选的实验都出现健康样本误检，均已撤回。最终版本没有这些改法。
