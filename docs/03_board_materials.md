## 顺便确认三件事（[04_board_facts.md](04_board_facts.md) 里有详细说明）

1. **JTAG 下载器**有没有？（板子上只有 2×7 排针，没有板载 USB-JTAG，没它就下不进程序）
2. **12V 电源适配器**有没有？（DC 圆孔，5.5×2.1mm，≥2A）
3. **HDMI 线和带 HDMI 输入的显示器**有没有？（板上只有 HDMI 输出，没 LCD 接口）
4. **OV5640 摄像头模块**有没有？（正点原子款，带 2×9 排线插在 `OLED/CAMERA` 排针上）
