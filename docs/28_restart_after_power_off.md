# 断电后重新启动 v2.4 优化版

当前默认版本为已上板复测的 v2.4，完整流程与结果见 [v2.4 说明](33_workflow_optimization_v2_4.md)。可给启动脚本传入 `-Version 2_1` 回退。

当前 PL bitstream 和 PS ARM 程序通过 JTAG 临时加载，没有写入 Flash 或制作 SD 启动镜像。断电后两者都需重新加载，但不需要重新编译。

PS 是 Zynq 芯片内的 ARM 处理器，运行板载程序。电脑负责下载及串口控制，不承担图片预处理或病斑检测。运行后若板卡保持独立供电，断开电脑仍可显示当前图片；当前切换样本使用串口命令。

## 下次操作

1. 断电接好 JTAG、USB 串口、HDMI 与板卡电源，保持当前 JTAG 启动拨码。此前项目记录为 ON/ON，以本板已验证设置为准。
2. 板卡上电，显示器选择正确 HDMI 输入。
3. 关闭占用 COM7 的串口终端，以及占用 JTAG 的其他调试连接。
4. 双击项目根目录的 `启动病斑演示.cmd`。
5. 等待下载和样本切换，默认停在第14张，通常需要几十秒（包括JTAG下载）。这里只加载现有程序并切换样本，不重新编译、不跑全24张统计。
6. 如果屏幕仍是彩条，按一次板上 KEY1 切换到图片源。
7. 启动脚本结束后会释放 COM7；可重新打开串口终端，115200、8N1，使用 n/b/p/o 等命令。

双击入口通过 `powershell.exe -NoProfile -ExecutionPolicy Bypass` 运行本项目脚本，仅对本次启动进程生效，不修改系统或用户的长期执行策略。

更快地停在第1张（健康样本，通常没有红框）：

```powershell
cd D:\FPGA比赛
./tools/start_pl_demo.ps1 -Sample 1
```

启动器依赖当前电脑上的 Xilinx SDK、`D:/fpga_build/sdk_ws/hw0/ps7_init.tcl`、已生成的 `system_top_v2_4.bit` 和项目中的 v2.4 ELF。更换电脑或移动这些目录时需要重新配置路径和驱动。

## 想脱离电脑上电自启动

需要另外制作包含 FSBL、PL bitstream 和 PS ELF 的启动镜像（通常为 BOOT.BIN），再按本板支持的 SD 或 QSPI 启动方式部署，并设置对应启动拨码。此项目前尚未执行，当前双击入口仍依赖电脑完成 JTAG 加载。

当前启动器默认 v2.4 优化版，默认停在第 14 张，该张完整换图实测约 254 ms，同图重检约 140 ms。保留 v2.1，可用 `./tools/start_pl_demo.ps1 -Version 2_1` 显式回退。
